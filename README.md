# Gate Wars

A browser airline strategy game. You run a three-jet starter airline out of JFK for 26 weeks against a rival, Liberty Skyways, which reacts to your moves.

- Choose aircraft, assign routes, set fares, and advance one week at a time
- A split-flap departure board shows load factor, profit, and the biggest reason each route made or lost money
- Disruptions (storms, fuel spikes, engine faults, crew sick-outs, rival fare sales) each come with three choices

All economics are simplified and fictional. The whole game is one file, `index.html`. Open it in any browser to play. Progress saves in your browser.
